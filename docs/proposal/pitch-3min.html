The concepts · 1:50–2:25
Four ideas, one vocabulary

How the skill thinks about a change

⇄
→

Two-way or one-way door

Two-way: deploy it, roll it back, the old code still works. One-way: it leaves state the old code can't handle.

V3

When the door closes

The deploy moment after which rollback stops being safe. Here: the 5 ms it takes Flyway to run V3.

ledger · reconciliation · reports

Blast radius

Every reader of the same table, column, topic or field. The one that breaks first is often not in the PR.

1 Expandadd the new
2 Migratecopy the data
3 Contractswitch readers
4 Dropremove the old

The rollback-safe split

The same change in four deploys. Proven live: 4 steps PASS the rollback test; PR #482 FAILS at stage 2.

Where it runs

Who it protects

  • Authors: fix it before review
  • Reviewers: see readers outside the diff
  • On-call: know if rollback helps
  • Finance and data: totals that don't drift
